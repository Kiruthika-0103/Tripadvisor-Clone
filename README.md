# 🌍 Tripadvisor Clone Website

## About the Project

The Tripadvisor Clone is a responsive travel website developed using HTML and CSS. The main aim of this project is to create an attractive and user-friendly interface that helps users explore travel destinations, discover exciting activities, and get inspiration for their next adventure.

The website features a navigation bar, travel search section, hero banner with an automatic image slideshow, interest-based activities, South India travel experiences, worldwide travel inspiration, and popular destinations. It also includes an attractive footer with useful links.

## ✨ Features

- **Hero Section:** An attractive banner with an automatic image slideshow.
- **Travel Search:** A search section for travel exploration.
- **Explore by Interest:** Discover activities related to outdoors, food, culture, and water.
- **South India Experiences:** Explore travel experiences and destinations in South India.
- **Travel Inspiration:** Discover places around the world.
- **Top Destinations:** Explore popular destinations through image cards.
- **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
- **Hover Effects:** Interactive visual effects for images and cards.
- **Footer:** Includes About, Explore, and Support links.
